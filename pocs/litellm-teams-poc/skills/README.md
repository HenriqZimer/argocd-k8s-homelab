# Skills

Organize uma skill por pasta, com seu `SKILL.md` e arquivos auxiliares. O Skills Gateway registra/publica os itens do catálogo pelo API/UI; os metadados e permissões devem ser mantidos aqui, enquanto segredos e tokens permanecem em Secrets Manager.

Na próxima etapa, adicione um reconciliador próprio para registro, publicação e grants de skills, sem acoplar esse lifecycle ao Job dos teams.
